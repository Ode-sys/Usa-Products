### Ode-specific document templates

**Invoice (Google Sheets):**
- Header: Odé | عودة logo + Tulkarm, Palestine
- Columns: Item · Qty · Unit Price · Total
- Footer: Payment terms + bank/PayPal details
- Language: bilingual (Arabic right, English left)

**WBR Report structure:**
```
1. Executive Summary (1 page)
2. Revenue Dashboard (charts)
3. Advertising Performance
4. Inventory Status
5. Action Items
```

**Client proposal:**
```
1. المشكلة (Problem — 1 paragraph)
2. الحل المقترح (Solution — 3 bullets)
3. النتائج المتوقعة (Expected outcomes)
4. الجدول الزمني (Timeline — table)
5. الاستثمار (Investment — pricing table)
6. الخطوة التالية (Next step — single CTA)
```
