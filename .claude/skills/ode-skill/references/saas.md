## Skills in This Domain

### WBRintel — Amazon/Walmart Analytics SaaS
**Architecture (2,148-line JSX):**
- Auth + RBAC (roles: admin, analyst, viewer)
- Modules: Advertising · Inventory · P&L · Audit
- Data source: Amazon SP-API + Walmart API
- Output: Weekly Business Review (WBR) reports

**Key screens to maintain:**
```
/ Dashboard (KPI overview)
/advertising (ACOS, TACOS, spend, revenue)
/inventory (days of stock, reorder alerts)
/pl (P&L by ASIN, category)
/audit (data quality checks)
/reports (WBR generator)
```

**WBR Metrics Standard:**
| Metric | Formula | Target |
|--------|---------|--------|
| ACOS | Ad Spend / Ad Revenue | < 25% |
| TACOS | Ad Spend / Total Revenue | < 12% |
| CVR | Orders / Sessions | > 12% |
| ROAS | Ad Revenue / Ad Spend | > 4x |
| IDS | Units / Daily Sales | > 30 days |
