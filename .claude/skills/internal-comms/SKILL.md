# internal-comms

Draft updates, FAQs, leadership notes, and team communication.

## When to use
When writing internal communications: all-hands updates, incident summaries, policy announcements, team FAQs, or leadership memos.

## Templates

### Status update
```
**Status: [On track / At risk / Blocked]**
What happened this week: ...
What's next: ...
Blockers: ...
```

### Incident summary
```
**What happened**: ...
**Impact**: ...
**Root cause**: ...
**What we did**: ...
**What we're doing to prevent recurrence**: ...
```

### FAQ format
**Q: [Question]**
A: [Direct answer in 1-3 sentences.]

## Tone principles
- Be direct. Lead with the conclusion.
- Use plain language. Avoid jargon.
- Be honest about uncertainty.
