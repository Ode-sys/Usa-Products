# hypothesis-generation

Generate research hypotheses and testable experiment directions.

## When to use
When a researcher has a domain area of interest and needs help generating specific, testable hypotheses.

## Process
1. Understand the domain: what is already known, what the key variables are.
2. Identify the knowledge gap: what is not yet explained or tested.
3. Generate 3-5 candidate hypotheses. Each must be:
   - Specific (names the variables)
   - Testable (can be falsified by an experiment or observation)
   - Grounded (connected to existing literature)
4. For each hypothesis, suggest: experimental design, key measures, potential confounds.
5. Rank hypotheses by: novelty, feasibility, impact if confirmed.

## Format
**H1**: [Hypothesis statement]
- Test: [How to test it]
- Measure: [What to measure]
- Confounds: [What might confound the result]
