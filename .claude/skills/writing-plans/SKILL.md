# writing-plans

Convert an approved design into a step-by-step implementation plan.

## When to use
After brainstorming produces a technical direction, use this skill to convert that direction into a concrete, ordered implementation plan before writing any code.

## Process
1. Take the approved technical direction statement as input.
2. Break the work into numbered steps, each representing one atomic change.
3. For each step specify: what changes, which files are affected, what the acceptance criterion is.
4. Flag any dependencies between steps.
5. Estimate relative complexity (small / medium / large) for each step.
6. Present the plan for user approval before execution begins.

## Output
A numbered implementation plan with file targets, acceptance criteria, and dependency notes.
