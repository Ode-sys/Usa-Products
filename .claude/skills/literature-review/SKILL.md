# literature-review

Synthesize papers into themes, gaps, methods, and takeaways.

## When to use
When the user has a set of papers (or a topic) and needs a structured synthesis, not just a summary.

## Process
1. Collect papers: titles, abstracts, or full text.
2. Group by theme: what recurring ideas, debates, or findings appear?
3. Identify the dominant methodology in the field (RCT, observational, computational, etc.).
4. Map the consensus vs. the contested claims.
5. Identify gaps: what questions remain unanswered?
6. Write a synthesis structured as: Background → Themes → Methods → Consensus → Gaps → Implications.

## Structure
- Intro: why this topic matters
- Theme sections (2-5): each summarizes a cluster of related papers
- Methodological notes
- Research gaps
- Conclusion
