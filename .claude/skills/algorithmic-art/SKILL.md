# algorithmic-art

Generate creative coded visuals, patterns, and p5.js style artwork.

## When to use
When the user wants generative art, visual patterns, or creative coding outputs rather than functional UI.

## Process
1. Ask for the aesthetic direction: geometric, organic, noisy, symmetrical, animated.
2. Choose the rendering approach: p5.js, canvas API, SVG, or CSS animations.
3. Implement the generative algorithm with tunable parameters.
4. Add interactivity (mouse, keyboard) if useful.
5. Export as a self-contained HTML file or artifact.

## Common patterns
- Perlin noise fields
- Recursive geometry (fractals, L-systems)
- Particle systems
- Grid-based cellular automata
- Fourier / frequency visualizations
