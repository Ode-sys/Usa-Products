# frontend-design

Create distinctive production-grade frontend interfaces with better taste.

## When to use
When building a UI from scratch or redesigning an existing interface and quality and aesthetic distinction matter.

## Process
1. Clarify the audience, brand tone, and primary user action.
2. Choose a visual direction: minimal, bold, editorial, or functional.
3. Define spacing scale, type scale, and color palette before writing components.
4. Build layout first (grid / flex), then components, then polish.
5. Check contrast ratios, focus states, and mobile breakpoints.
6. Test in a real browser before declaring done.

## Principles
- Whitespace is a design element, not empty space.
- Hierarchy through size and weight before color.
- One primary action per screen.
