# doc-coauthoring

Collaborate on long-form writing and structured document drafts.

## When to use
When producing a long document (report, white paper, proposal, spec) collaboratively with a user over multiple turns.

## Process
1. Agree on the document structure (outline) before writing any section.
2. Write one section at a time. Present it for feedback before continuing.
3. Keep a running outline with status: draft / reviewed / final.
4. On revision requests: edit the specific section, not the whole document.
5. When all sections are approved, assemble the final document.

## Writing principles
- Topic sentence first in every paragraph.
- Active voice by default.
- One idea per paragraph.
- Define terms on first use.

## Output formats
Markdown (for export), docx, pdf, or Google Docs paste format.
