# infographics

Transform complex material into clear audience-friendly visual summaries.

## When to use
When complex data, a process, or a concept needs to be communicated visually to a non-expert audience.

## Process
1. Identify the single core message the infographic must communicate.
2. Choose the infographic type: process flow, comparison, timeline, data story, geographic map.
3. Reduce to 5-7 key data points or steps. Cut everything else.
4. Sketch the layout before building: top-to-bottom or left-to-right reading order.
5. Build in SVG or HTML+CSS for scalability.
6. Use icons (Font Awesome or SVG) to replace words where possible.
7. Limit to 3 colors. Use contrast for hierarchy.

## Tools
- D3.js for data-driven infographics
- SVG for static visual explanations
- Mermaid for flow diagrams in markdown
