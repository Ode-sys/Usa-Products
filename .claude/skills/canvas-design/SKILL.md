# canvas-design

Create precise visual layouts for PNG, PDF, and presentation-like outputs.

## When to use
When the output must be a pixel-precise visual document: a one-pager, a poster, a certificate, or a PDF report layout.

## Process
1. Define canvas dimensions (A4, Letter, 1920×1080, etc.) and output format.
2. Lay out content zones: header, body, sidebar, footer.
3. Place text, images, and graphic elements with explicit coordinates.
4. Apply consistent padding and alignment grid.
5. Export to the target format (PNG / PDF / SVG).

## Tools
- Use HTML/CSS with fixed dimensions for PDF/PNG export via headless browser.
- Use SVG for vector outputs.
- Use canvas API for pixel-level control.
