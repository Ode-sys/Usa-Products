# amazon-pnl-analysis

تحليل الربح والخسارة الحقيقي لكل ASIN على Amazon — يكشف المنتجات الرابحة
فعلاً من الخاسرة بعد احتساب كل التكاليف.

## متى تُفعَّل
عند طلب "P&L"، "ربح وخسارة"، "شو ربحي الحقيقي"، "profit margin"،
"هل هالمنتج مربح"، "حساب الهامش"، "unit economics".

## المدخلات المطلوبة

**إلزامية:**
- تقرير المبيعات (Ordered Product Sales + Units)
- تكلفة البضاعة (COGS) لكل ASIN — يُدخلها المستخدم

**اختيارية (تُحسّن دقة التحليل):**
- تقرير FBA Fees
- تقرير الإعلانات (ACoS/Spend)
- تكاليف الشحن من المورد
- تكاليف العبوة والإعداد

## هيكل حساب الربح لكل وحدة

```
سعر البيع (Selling Price)                       $ XX.XX
─────────────────────────────────────────────────
(-) رسوم Amazon Referral Fee                    $ (X.XX)   ~15% أو حسب الفئة
(-) FBA Fulfillment Fee                         $ (X.XX)   حسب الحجم والوزن
(-) FBA Storage Fee (monthly)                   $ (X.XX)   حسب حجم المخزون
(-) Cost of Goods Sold (COGS)                   $ (X.XX)   من المستخدم
(-) Inbound Shipping (per unit)                 $ (X.XX)   إذا متوفر
(-) PPC Cost (per unit sold)                    $ (X.XX)   إجمالي إنفاق ÷ وحدات مباعة
─────────────────────────────────────────────────
= Net Profit per Unit                           $ X.XX
= Net Margin %                                  X.X%
= ROI على COGS                                  XXX%
```

## مستويات التحليل

### المستوى 1: هامش الوحدة الواحدة
ربح/خسارة لكل وحدة مباعة — يكشف المشكلة الهيكلية.

### المستوى 2: الربح الإجمالي للفترة
```
صافي الربح الإجمالي = Net Profit per Unit × عدد الوحدات المباعة
```

### المستوى 3: تحليل نقطة التعادل
```
Break-even Units = إجمالي التكاليف الثابتة ÷ هامش المساهمة per unit
Break-even Price = COGS + كل الرسوم الثابتة per unit
```

### المستوى 4: تصنيف المنتجات

| الفئة | المعيار | التوصية |
|-------|---------|---------|
| ⭐ Star | هامش > 25% + حجم مبيعات عالٍ | استثمر أكثر — Scale up |
| 💰 Cash Cow | هامش 15-25% + حجم عالٍ | حافظ عليه — لا تعبث بالسعر |
| ❓ Question Mark | هامش > 25% + حجم منخفض | حسّن الزيارات والتحويل |
| ⚠️ Problem | هامش < 15% أو خسارة | راجع السعر أو التكلفة أو أوقف |

## قواعد صارمة
- لا تفترض أي تكلفة (COGS، Fees) — إذا ناقصة اطلبها من المستخدم أو اذكرها صراحةً
- Amazon Referral Fee تختلف بحسب الفئة — لا تفترض نسبة ثابتة
- Storage Fees موسمية (Q4 أعلى) — اذكر إذا الفترة في Q4
- ROI يُحسب على COGS وليس على سعر البيع
