# brand-guidelines

Apply brand rules consistently across copy, visuals, layouts, and docs.

## When to use
When producing any external-facing artifact (marketing copy, docs, slides, emails) and brand consistency is required.

## Process
1. Load or define brand rules: logo usage, color palette, voice and tone, typography.
2. Before generating content, check each rule against the output.
3. Flag any violations and correct them.
4. Produce a brand-compliant artifact.

## Checks
- Color: only approved palette values used.
- Typography: correct font families and weights.
- Voice: tone matches brand personality (formal/casual/technical).
- Logo: not distorted, sufficient clear space.
- Imagery: style consistent with brand aesthetic.
