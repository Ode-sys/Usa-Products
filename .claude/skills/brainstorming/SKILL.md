# brainstorming

Refine a rough idea into a clear technical direction before implementation.

## When to use
Invoke when the user has a vague idea, feature request, or problem statement that needs to be sharpened into a concrete technical plan before any code is written.

## Process
1. Ask the user to describe their rough idea in one or two sentences.
2. Identify the core goal, the constraints, and the unknowns.
3. Generate 2-3 distinct technical directions, each with a brief tradeoff summary.
4. Ask the user to pick a direction or combine elements.
5. Produce a one-paragraph technical direction statement ready to hand off to writing-plans.

## Output
A clear, agreed-upon technical direction statement. No code, no implementation yet.
